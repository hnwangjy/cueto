# Cueto 1.0.6

## 改进

- **菜单栏内容更清晰**：应用名称和播放按钮现在使用高对比度显示，在深色菜单栏上更容易辨认。
- **交互反馈更明确**：优化来源按钮和播放控制按钮的按压、选中背景，打开播放面板时可以清楚看到当前选中来源。
- **来源名称显示更完整**：重新分配菜单栏空间，减少应用名称被过早截断的问题。

## 修复

- 修复播放信息面板打开后仍显示为非激活灰色状态的问题，现在会立即使用系统强调色。

## 安装说明

此版本已使用 Developer ID 签名，但尚未经过 Apple 公证。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto 并选择“打开”。
