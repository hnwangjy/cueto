# Cueto 1.0.9

## 新功能

- **更清晰的空闲状态**：没有音频应用激活时，菜单栏会显示 `waveform.mid` 图标和 Cueto 名称，不再只显示应用图标。
- **空闲面板**：无音频播放时仍可点击菜单栏打开面板，快速进入 Cueto 设置或退出应用。

## 改进

- **来源出现更自然**：音频应用开始播放时，Cueto 空闲状态会向左退出，新应用的图标和名称从右侧进入。
- **保持菜单栏简洁**：空闲状态会隐藏播放控制和下拉箭头，只保留 Cueto 的入口信息。

## 安装说明

此版本已使用 Developer ID 签名，但尚未经过 Apple 公证。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto 并选择“打开”。
