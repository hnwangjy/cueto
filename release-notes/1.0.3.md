# Cueto 1.0.3

## 新功能

- **更方便地管理 Cueto**：现在打开 Cueto 会进入独立设置窗口，可以选择登录 Mac 时自动启动。
- **自动获取新版本**：可开启或关闭自动检查更新，也可以随时手动检查新版本。

## 改进

- **更直观的播放控制**：前进与后退按钮改用更清晰的系统图标。
- **更紧凑的菜单栏布局**：缩小控件间距，减少 Cueto 占用的菜单栏空间。
- **正确的打开行为**：“打开 Cueto”现在会打开 Cueto 设置，而不是跳转到当前播放来源。

## 安装说明

此版本已使用 Developer ID 签名，但尚未经过 Apple 公证。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto 并选择“打开”。
