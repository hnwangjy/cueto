# 小宇宙异常退出后自动恢复

- 入口在设置的“实验功能”页，默认关闭。
- 仅处理 Cueto 运行期间观察到的小宇宙退出；不回溯启动 Cueto 之前的退出，也不在开关开启时重放历史报告。
- 匹配新的 `Podcast-*.ips` / `小宇宙-*.ips`，要求 bundle ID、PID、报告时间和可获取的进程启动时间一致；终止原因必须为 `RUNNINGBOARD / 0xDEAD10CC`。
- 诊断报告在后台读取，退出后分阶段等待，最多约一分钟。报告不完整时等待后续写入；无法读取时停止本次恢复，并在设置中提示。
- 重新检测到小宇宙运行、关闭开关或系统退出时取消等待。不发送播放指令，后台请求打开应用；应用自身的启动播放行为不由 Cueto 控制。
- 两分钟内最多尝试一次，半小时最多三次。尝试时间保存在本机偏好中，重启 Cueto 不清空限流；不复制、上传或记录完整诊断报告。

验证：`CosmosCrashRecoveryTests.swift` 覆盖双 JSON 对象的 IPS 格式、单 JSON 对象、错误应用、错误进程、启动时间不符、旧报告、不同终止原因、报告尚未生成／不完整、文件修改时间过滤、目录读取失败及恢复预算。Debug 构建通过，真实设置页的开关已验证开启与关闭，测试后恢复关闭；开启时未显示读取错误。

尚未刻意制造小宇宙崩溃，真实故障后自动拉起的完整流程仍待自然复现。随 1.3.4 作为默认关闭的实验功能发布。
