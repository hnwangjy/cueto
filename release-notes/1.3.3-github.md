## 新增

- 播放面板显示系统当前播放封面，并在右上角显示来源应用图标；未提供封面时显示应用图标。
- Apple Music 面板显示前一句、当前句和后一句，点击歌词可跳转并保留原有播放或暂停状态。
- 在“设置 → 歌词”按歌曲提前或延后校时，每次 0.5 秒，支持归零并在本机记住。
- 设置窗口增加“通用、歌词、隐藏应用、实验功能”侧栏分类。
- 侧栏补齐悬停、按下、选中和键盘方向键切换，并适配减少动态效果。

## 修复

- 修复暂停时跳至歌词起点可能因定位精度而误显示间奏的问题。
- 缩短小宇宙字幕的固定宽度，长句继续滚动，避免随句长伸缩。
- 加重菜单栏字幕字重，改善阅读清晰度。
- 重排播放面板：封面与节目信息置顶，进度、字幕和应用列表依次展示。
- 恢复独立的系统标题栏，避免透明标题栏透出后方窗口文字。

## 删除

- 移除播放面板中的校时按钮，统一放入设置的歌词页。
- 移除侧栏选中项的蓝色粗焦点框，保留键盘导航。

## 安装

打开 DMG，将 Cueto 拖入“应用程序”。已安装 Cueto 的用户可在设置中检查更新。
