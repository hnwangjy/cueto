# Cueto 1.0.5

## 改进

- **更可靠的菜单栏控制**：重做菜单栏按钮的点击处理，改善在新版 macOS 上反复点击却没有响应的问题。
- **控制行为与播放器一致**：音乐类播放器现在使用上一首和下一首；小宇宙与播客应用继续使用后退 15 秒和前进 30 秒。

## 安装说明

此版本已使用 Developer ID 签名，但尚未经过 Apple 公证。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto 并选择“打开”。
