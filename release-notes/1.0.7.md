# Cueto 1.0.7

## 新功能

- **识别多个音频来源**：同时有多个应用发声时，菜单栏会显示清晰的数量提示；打开面板即可查看所有正在发声的应用以及当前可控制来源。
- **闲时自动收起**：没有可控制的播放内容时，Cueto 会收起为单独的应用图标，减少菜单栏占用。

## 改进

- **来源切换更自然**：播放来源变化时，原应用向左退出，新应用从右侧进入，让切换过程更容易察觉。
- **数量提示更清楚**：数字提示移到应用图标左侧，并使用系统强调色提高可读性。

## 安装说明

此版本已使用 Developer ID 签名，但尚未经过 Apple 公证。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto 并选择“打开”。
