# Cueto

Cueto 是一个轻量的 macOS 菜单栏媒体控制器。它把播放指令准确交给当前正在发声的应用，让你无需切换窗口就能控制小宇宙、浏览器、音乐或播客。

![Cueto App Icon](space_playbar/Assets.xcassets/AppIcon.appiconset/Cueto-256.png)

## 能做什么

- 自动识别 macOS 当前的 Now Playing 应用，并显示真实应用名称和图标
- 在菜单栏直接播放或暂停
- 后退 15 秒、前进 30 秒
- 点击来源名称查看当前标题、作者、实时播放进度、总时长与剩余时长，并打开 Cueto 设置
- 可选择登录 Mac 时自动启动，并可随时开启或关闭自动检查更新
- 可在 Cueto 设置中隐藏指定应用，让它们不出现在控制栏、来源数量和播放来源列表中
- 点击菜单栏打开面板时，可查看正在输出及已检测但暂未输出的音频应用；应用退出后会从列表移除
- 支持手动立即检查新版本
- 适用于支持 macOS 系统媒体控制的小宇宙、浏览器、音乐与播客应用

## 安装

1. 从 [Releases](https://github.com/hnwangjy/cueto/releases) 下载最新的 DMG。
2. 打开 DMG，将 **Cueto** 拖入“应用程序”。
3. 启动 Cueto，控制条会出现在菜单栏。

> 首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto，选择“打开”。

## 使用方式

开始播放任意受支持应用中的内容，Cueto 会自动显示当前来源。左侧点击应用名称可以查看播放信息；右侧三个按钮分别用于后退、播放/暂停和前进。

在播放信息面板或菜单栏右键菜单中选择“打开 Cueto”，可以管理“登录时自动启动”“自动检查更新”和“隐藏应用”，也可以立即检查新版本。隐藏应用可从当前运行的应用中勾选，或通过“添加应用…”选择未运行的 `.app`。

Cueto 调用 macOS 的系统 Now Playing / MediaRemote 能力。菜单栏的播放控制无需切换窗口。

音频应用列表中的“前往”按钮会打开并激活对应应用，方便在应用内继续操作。浏览器来源会前往浏览器应用，不会自动定位到具体的音视频标签页。

设置中的“实验功能（BETA）”包含“菜单栏字幕 · 小宇宙”和“灵动岛面板”，可分别开启或关闭。

字幕宽度可选“短／适中／长”，默认适中，选择会保留。短句居中显示，超出所选宽度的长句自动向左滚动。

在带刘海的 MacBook 屏幕上，把鼠标移到刘海区域并停留片刻，即可在刘海下方展开 Cueto 面板，操作播放控制、查看来源和字幕，或打开设置、退出应用。移入面板可继续操作，移开后自动收起；也可以点击关闭按钮。此入口默认开启，可在“实验功能”中关闭“灵动岛面板”，无需额外授权。没有刘海的屏幕继续使用菜单栏入口。

在 Cueto 设置中开启“菜单栏字幕 · 小宇宙”，并点击“授权…”，按 macOS 提示授予 Cueto 辅助功能权限。打开小宇宙播放页并显示字幕后，Cueto 会在独立的菜单栏区域展示读取到的字幕行。换句时轻微上移并淡化切换；长句停留片刻后向左滚到句尾，不循环，悬停也可查看全文。同一句补字和切换宽度时保留阅读位置；新句到来立即切换，与面板使用相同来源更新，不等待旧句滚完。开启系统“减少动态效果”时不自动滚动，只保留淡化和截断。字幕功能默认关闭，不采集音频或上传文字。目前基于小宇宙播放页已观察到的字幕结构读取；页面结构变化、关闭字幕或未获得授权时不会显示。系统媒体信息本身不提供这份字幕。

字幕只读取带节目封面的默认播放页中，封面和播放控制之间的小字幕区域，优先按位置选取中间可见行，不拼接上下文。字幕位置由小宇宙自身同步。此开关独立读取小宇宙，不要求系统当前媒体来源也恰好是小宇宙。展开的完整字幕页不作为读取来源。请保持默认页的小字幕开启；Cueto 不会自动操作小宇宙切换页面。跨桌面保留已找到的窗口引用，但能否持续更新仍取决于小宇宙实际提供的字幕文本。该功能仍属实验功能。

“未输出音频”只表示检测到该应用的音频进程、但当前没有活动输出，不一定代表它有一段已暂停且可恢复的媒体。部分应用在暂停后会销毁音频进程；若它也不是当前 Now Playing 会话，Cueto 无法从系统接口可靠地列出它。

## 系统要求

- macOS 26.7 或更高版本
- 当前 Release 同时支持 Apple Silicon（arm64）和 Intel（x86_64）

## 开发

使用 Xcode 打开 `space_playbar.xcodeproj` 后运行 `space_playbar` Scheme。项目通过 Swift Package Manager 使用 [MediaRemoteAdapter](https://github.com/ejbills/mediaremote-adapter) 和 [Sparkle](https://sparkle-project.org/)。

## 说明

Cueto 依赖 macOS 的非公开 MediaRemote 接口，因此更适合作为个人工具和开源实验项目；系统升级后相关行为可能发生变化。
