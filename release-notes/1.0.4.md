# Cueto 1.0.4

## 新功能

- **播放进度一目了然**：点击当前播放来源后，可以查看实时进度条、已播放时间、总时长和剩余时间。

## 修复

- **恢复小宇宙的前进与后退控制**：改用精确播放位置跳转，后退 15 秒和前进 30 秒现在可以正常生效。

## 安装说明

此版本已使用 Developer ID 签名，但尚未经过 Apple 公证。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto 并选择“打开”。
