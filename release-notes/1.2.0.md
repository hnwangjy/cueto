# Cueto 1.2.0

## 新功能

- 音频应用列表现在也会显示已检测到但暂未输出声音的应用，点击“前往”即可打开对应应用。
- 新增实验功能“灵动岛面板”：悬停 MacBook 刘海即可向下展开播放面板，支持弹性动画、毛玻璃材质和圆角。
- 新增实验功能“菜单栏字幕 · 小宇宙”：授权后可读取默认播放页中间的小字幕，在菜单栏和面板中显示。

## 改进

- 设置页重新分组，精简说明文字，并支持滚动，方便在笔记本屏幕上使用。
- 优化音频应用列表的状态展示和“前往”按钮。

## 实验功能说明

字幕和灵动岛面板可在设置的“实验功能”中分别开关。字幕依赖小宇宙界面更新，跨桌面时可能停止刷新；不读取展开的完整字幕页。灵动岛面板适用于带刘海的 MacBook 屏幕。

## 安装说明

下载并打开 DMG，将 Cueto 拖入“应用程序”。首次启动时如果 macOS 阻止打开，请在 Finder 中右键 Cueto，选择“打开”。
