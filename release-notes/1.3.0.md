# Cueto 1.3.0

Cueto 现已支持简体中文和英文，界面跟随 macOS 为应用选择的语言。

Cueto now supports Simplified Chinese and English and follows the language selected for the app in macOS.

打开 DMG，将 Cueto 拖入「应用程序」。已安装 Cueto 的用户也可以在设置中检查更新。

Open the DMG and drag Cueto into Applications. Existing users can check for updates in Cueto Settings.
