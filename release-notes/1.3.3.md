# Cueto 1.3.3

播放面板新增封面，重新整理节目、歌词与应用列表的排版。Apple Music 支持查看前后句、点击歌词跳转，并在设置中按歌曲调整同步时间。设置改为左右分栏，小宇宙菜单栏字幕采用更紧凑的固定宽度。

The playback panel now shows artwork with a cleaner layout. Apple Music adds surrounding lyrics, click-to-seek, and per-track timing adjustment in Settings. Settings now uses a sidebar, and Xiaoyuzhou captions use more compact fixed widths.
